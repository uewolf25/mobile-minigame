# mobile-minigame 仕様メモ

## これは何か

スマホの片手操作だけで遊べる小さなゲームを並べた、個人用のミニゲーム置き場。
卓球スクールの待ち時間や、子ども・保護者に「ちょっとやってみて」と渡す用途も想定する。

- 遊ぶ場所: iPhone / Android のブラウザ（GitHub Pages 配信）
- 1回の遊び時間: 30秒〜2分
- 操作: 縦持ち・片手・親指のみ。長押しや2本指は使わない

## イメージ像

**2色刷りのリソグラフ印刷**。インクの版が少しズレて重なった印刷物の質感を、
画面上で再現する。昭和のゲームセンターのチラシや、駄菓子屋の景品パッケージに近い温度感。

具体的には:

- ぼかし影（`blur`）は使わない。影は必ず**硬いオフセット影**（`box-shadow: 5px 5px 0 <accent>`）
- 角丸はボタンだけ（`999px` の完全な丸）。パネル・マス・盤面は角丸ゼロ
- グラデーションは使わない。色はすべてベタ塗り
- 面はインクの版のように、境界をはっきり分ける
- タイトルは同じ文字を2回重ねて数px ずらす「版ズレ」表現

避けたい方向: SaaS ダッシュボード風のカード＋薄いグレー影、
ネオン＋ダークのゲーミング配色、絵文字によるアイコン代用。

### パレット

| 変数 | 値 | 役割 |
| --- | --- | --- |
| `--ink` | `#131C3D` | 背景の基調（濃紺） |
| `--ink-deep` | `#0B1027` | 盤面・くぼみ |
| `--ink-line` | `#2B3766` | 罫線・枠 |
| `--paper` | `#EFEAE0` | 文字・ボタン地・ボール |
| `--mist` | `#8E96B4` | 補助テキスト |
| `--orange` | `#FF5230` | 第2インク |
| `--yellow` | `#FFC93C` | 第3インク |
| `--teal` | `#3FC7B4` | 第4インク |

ゲームごとに `--accent` を1色だけ割り当てる（反射=黄 / そろえる=橙 / くぐる=青緑 /
おぼえる=橙 / たたく=黄）。1画面に強い色を2つ以上置かない。

### 文字

日本語ゴシック1系統のみ。ウェイトとサイズの差だけで階層を作り、書体は増やさない。
数値は `font-variant-numeric: tabular-nums` で桁が揺れないようにする。
ラベルの全角スペース強調や、英数字の大文字トラッキング装飾は使わない。

### 動き

動きは**プレイヤーの操作に対する返事だけ**に使う。タイル出現の弾み、
叩いたボールの消え方、ボタンの沈み込み。ページ読み込み時の順次フェードインは入れない。
`prefers-reduced-motion` を尊重する。

## 技術方針

- ビルド不要。npm もバンドラも使わない
- 1ゲーム = 1フォルダ = `index.html` 1枚に HTML/CSS/JS を全部入れる
- 共通の色・ボタン・レイアウトだけ `shared/arcade.css` に置く
- 外部CDN・Webフォント・画像ファイルへの依存ゼロ。アイコンはインラインSVG
- ES5相当の素のJS。フレームワークもTypeScriptも導入しない
- 記録は `localStorage`、キーは `mmg.<フォルダ名>.best`。
  必ず try/catch で包み、保存できない環境でもゲームは動くこと
- サーバー送信なし。スコアは端末内に閉じる

### スマホ対応の必須事項

- `100dvh` と `env(safe-area-inset-*)` でノッチとホームバーを避ける
- `touch-action: manipulation` と `user-scalable=no` で連打時のズームを防ぐ
- 盤面のスワイプは `touchmove` を `passive: false` で `preventDefault` し、
  ページスクロールに取られないようにする
- タップ判定は `pointerdown`（`click` は遅延が出る）
- 端末幅が変わっても難易度が変わらないよう、Canvas は論理座標を固定する

## ファイル構成

```
index.html          一覧ページ。各ゲームの記録も読み出して並べる
shared/arcade.css   共通トークン
reflex/index.html   反射
merge/index.html    そろえる
dodge/index.html    くぐる
memory/index.html   おぼえる
whack/index.html    たたく
```

各ゲーム画面は共通の骨格を持つ:
ヘッダー（もどる＋タイトル）→ 数値ストリップ → 遊ぶ面 → 下部の主ボタン。
主ボタンは親指の届く最下部に固定する。

### 一覧表

| ゲーム | フォルダ | 操作 | `--accent` | 記録キー | 記録の中身 |
| --- | --- | --- | --- | --- | --- |
| 反射 | `reflex/` | タップ | 黄 | `mmg.reflex.best` | 最速の反応（ms・小さいほど良い） |
| そろえる | `merge/` | スワイプ | 橙 | `mmg.merge.best` | 得点 |
| くぐる | `dodge/` | タップ | 青緑 | `mmg.dodge.best` | くぐった数 |
| おぼえる | `memory/` | タップ | 橙 | `mmg.memory.best` | 到達した長さ |
| たたく | `whack/` | タップ | 黄 | `mmg.whack.best` | 叩いた数 |

キーボードだけでも遊べる。矢印キー（そろえる）、スペース（反射・くぐる）、
数字キー（おぼえる=1〜4 / たたく=1〜9）が使える。

### 遊ぶ

リポジトリの Settings → Pages で `main` ブランチのルートを配信先にすると
`https://uewolf25.github.io/mobile-minigame/` で開ける。
手元で見るときは、このフォルダを静的配信すればよい（`file://` でも動くが、
`localStorage` がブロックされて記録が残らない）。

## 各ゲームの仕様

### reflex — 反射

赤い面が黄色に変わった瞬間にタップし、反応速度をミリ秒で計測する。

- タップで開始 → 1200〜4200ms のランダム待機（赤・「まて」）→ 黄・「いま！」
- 黄になる前に押したら「はやい」でやり直し（記録に残さない）
- 表示するのは 今回 / 直近5回の平均 / 最速 の3つ
- 記録キー `mmg.reflex.best`（最小値を保存）

### merge — そろえる

4×4のスワイプパズル。同じ数字がぶつかると合体する。

- 新規タイルは 2 が90%、4 が10%
- 1手ぶんだけ戻せる（`1手もどす`）
- 2048 到達で一度通知を出すが、そのまま続行できる
- 空きがなく隣接する同値もない状態で終了
- 合体したマスと新しく出たマスは 160ms の弾みアニメーション
- 記録キー `mmg.merge.best`（得点）

### dodge — くぐる

タップで浮かせて、流れてくる壁のすき間を抜ける。

- 論理座標は幅300で固定、高さは実際の縦横比から算出する
- 重力 `2.6 * H`、タップ時の初速 `-0.80 * H`
- 壁の速度 `(0.52 + min(score, 25) * 0.008) * W`
- 壁の幅 `0.14 * W`、壁の間隔 `0.72 * W`
- すき間 `max(0.19, 0.29 - n * 0.006) * H`（進むほど狭くなるが下限あり）
- 天井・床への接触も失敗
- 記録キー `mmg.dodge.best`（くぐった数）

### memory — おぼえる

光った順番をなぞり返す。1回ごとに1つ長くなる。

- 2×2の4パッド。色は 橙 / 黄 / 青緑 / 紙色
- 音は WebAudio の triangle 波、262 / 330 / 392 / 523 Hz
- 再生間隔 `max(280, 620 - 長さ * 22)` ms
- 音が出せない環境でも進行できること（try/catch で握りつぶす）
- 記録キー `mmg.memory.best`（到達した長さ）

### whack — たたく

3×3から出てくるボールを30秒で叩く。卓球のボールをモチーフにする。

- 出現間隔 760ms → 380ms、滞在時間 950ms → 530ms に線形で変化
- 空振り（何もないマスをタップ）は減点しない。軽く揺らすだけ
- 残り時間はバーと秒数の両方で見せる
- 記録キー `mmg.whack.best`（叩いた数）

## やらないこと

- ログイン、アカウント、オンラインランキング
- 広告、外部解析、Cookie
- 課金・スタミナ・ガチャ的な要素
- 横向き専用のレイアウト
- ビルド工程の導入（React / Vite / TypeScript / Tailwind）
- 効果音ファイルや画像アセットの追加（音は WebAudio で合成する）

## 受け入れ条件

新しくゲームを足すとき、または既存を直すときは以下を満たすこと。

- [ ] `index.html` 1枚で完結し、`shared/arcade.css` 以外を読み込まない
- [ ] iPhone 縦持ち・幅375pxで、スクロールなしに全要素が収まる
- [ ] 連打してもページがズーム／スクロールしない
- [ ] `localStorage` が使えない環境でも例外を出さずに遊べる
- [ ] キーボードだけでも一通り操作でき、フォーカスリングが見える
- [ ] 一覧ページに記録が出るよう `mmg.<名前>.best` を保存している
- [ ] 一覧ページにタイル（インラインSVGのアイコン付き）を追加した
- [ ] README の一覧表を更新した

## 今後やりたいこと（Issue 候補）

- 「たたく」に卓球スクール向けモード（コーチが人数を入れて順番を出す）
- 記録の書き出し／読み込み（JSONをコピペで移せると端末を変えても残る）
- 一覧ページに直近の記録更新日を出す
- 「くぐる」の当たり判定を、円と長方形の最近接点で厳密に取る
- ホーム画面追加時のアイコンとスプラッシュ（`manifest.json` 追加）
- 効果音の音量トグル（`memory` 以外にも音を足すなら必要）
